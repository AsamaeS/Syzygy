# Hardware - Syzygy 

Simulation-first hardware design for the Cooperative Microgrid Energy Orchestrator.

## Structure
- `Documentation/` – Design decisions, calculations, scope, glossary
- `Pinout/` – GPIO map and machine-readable pinout
- `schematics/` / `kicad/` – KiCad source and PDF exports
- `Wokwi/` – Simulation project
- `LTspice/` – Analog analysis
- `bom/` – Bill of Materials
- `Reports/` – Final hardware report
